# AI教材资源导航

这是一个低成本启动的响应式网站/H5，用来整合 AI 工具百科、课程合集、岗位使用指南和工具对比页。当前版本不需要数据库，也不需要安装依赖，直接打开 `index.html` 就能浏览。

## 怎么打开

双击 `index.html`，或把整个文件夹部署到任意静态网站托管服务。

## 怎么更新内容

主要维护 `content-data.js`：

- `tools`：AI工具百科，包含官网、注册方式、价格、适合岗位、使用场景、优缺点、替代工具、更新时间。
- `tutorials`：课程合集，包含入门教程、岗位教程、案例教程、提示词模板、FAQ。
- `routes`：岗位路线，包含学生、电商、职场、运营、设计、程序员、教师、销售、HR、短视频创作者。
- `comparisons`：工具对比页面选题，适合后续扩展成 SEO 文章。

也可以打开 `editor.html` 使用站长编辑后台：

- 左侧选择内容类型和具体条目。
- 右侧直接改表单字段。
- 点“保存到本机预览”后，前台会读取预览内容。
- 点“导出 content-data.js”可以生成新版内容文件，用于正式替换。
- 当前是静态站点，编辑后台不会自动写入源文件；真正上线后可接数据库和管理后台。

图文教程图片放在 `assets` 文件夹：

- `guide-register.png`：注册教程。
- `guide-install.png`：安装或打开方式。
- `guide-use.png`：基础使用流程。
- `guide-remote-help.png`：远程帮助流程预留。

后续如果你有真实截图，直接用同名图片替换即可。

每个工具卡片现在有三个入口：

- `查看详情`：只看工具本身的信息、适合岗位、场景和替代工具。
- `官网`：跳转到工具官网。
- `安装教程`：打开该工具对应的注册、安装、第一次使用和远程帮助图文步骤。

新增工具时复制一个已有工具对象，改掉这些字段即可：

## 推荐更新节奏

- 每周新增 5 个工具。
- 每周更新 3 篇教程。
- 每周补 1 条岗位路线或对比选题。
- 每次更新都检查官网、价格、注册方式和限制是否变化。

## 上线前检查

- 手机端可以正常搜索、筛选、打开详情。
- 每个工具详情页都回答：怎么注册、怎么用、适合谁、是否收费、有什么替代品。
- 页面标题和描述包含关键词，例如“AI工具百科”“AI课程合集”“岗位AI指南”。
- 上线后提交百度搜索资源平台和 Google Search Console。

## 下一阶段

当网站内容达到 100 篇以上，并且有稳定访问后，再做微信小程序。小程序可以重点做收藏、每日推荐、微信群传播入口和搜索，不建议一开始就做独立 App。

## 社区功能说明

当前已经加入社区原型：

- 登录 / 注册演示：保存在当前浏览器本机。
- 问答广场：可以发布问题、评论回复。
- 视频教程：创作者可以发布教程标题、简介和视频链接。
- 创作者中心：投稿后能看到投稿状态、我的投稿、点赞播放和打赏演示数据。
- 打赏演示：会记录模拟金额，但不会产生真实付款。

真实上线时需要补充：

- 后端账号系统：手机号、邮箱、微信登录、密码或验证码。
- 数据库：保存用户、帖子、评论、视频、打赏订单。
- 内容审核：问题、评论、视频链接、头像和昵称都要能审核。
- 视频能力：建议先用 B 站、视频号、抖音等外链，后期再做自有视频存储。
- 支付能力：接微信支付、支付宝或平台支付，并处理订单、退款、分账、风控和发票等问题。

## 远程帮助规划

远程帮助建议放到第二阶段，不要一开始就做得太重。可以先用社区提问承接需求，后面再加入：

- 预约表单：用户选择工具、问题类型、方便时间。
- 服务方式：微信、企业微信、腾讯会议、ToDesk 或向日葵。
- 服务记录：安装了什么、解决了什么、还有什么待办。
- 收费方式：单次远程帮助、会员包月、创作者打赏。

## 创作者视频上传与审核

现在创作者中心已经支持“手机号登录 + 本地视频上传 + 待审核”流程：

- 用户进入首页的“创作者中心”，用手机号和验证码登录。未配置腾讯云时，演示验证码是 `123456`。
- 创作者填写视频标题、适合人群、使用工具、标签、简介，并选择本地 MP4 视频和封面图。
- 视频提交后状态为“待审核”，不会直接公开。
- 站长打开隐藏后台 `editor.html`，选择“视频审核”，可以通过、驳回或下架。
- 通过后，后台会自动把视频生成一条课程内容，课程合集里可以点击进入学习视频页面。

腾讯云真实上线时，需要配置 `cloudbase-config.js`：

- `cloudbase.envId`：你的 CloudBase 环境 ID。
- `cloudbase.smsLoginEnabled`：开通手机号验证码后改为 `true`。
- `vod.appId`：腾讯云点播 AppID。
- `vod.uploadSignatureUrl`：用于生成 VOD 上传签名的 CloudBase 云函数地址。
- `vod.playerLicenseUrl`：如使用 TCPlayer 播放器授权，则填写播放器 License URL。

注意：不要把腾讯云 SecretId、SecretKey 或任何管理员密钥写进前端文件。上传签名必须由云函数生成。
